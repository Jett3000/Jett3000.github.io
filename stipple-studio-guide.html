Stipple Studio

01 Generation

  • AttemptsMore placement attempts fill the image more consistently, with additional processing time.
  • Spawn RadiusLower values capture finer detail and create denser plots. Ensure your Pen Width is accurate in the Page Setup for best results.
  • HighlightsSets the maximum spawn-radius multiplier, spreading samples through bright areas.
  • ShadowsShapes image luminance so darker regions receive denser samples.

Click the canvas to try spawning a sample in an area that needs more coverage.

02 Page setup

Choose from standard paper sizes or select custom size to enter dimensions in inches or millimetres; unitless values are interpreted as millimetres. Page dimensions are limited to 64in.

Pen Width will affect the spawning density and the exported stroke width.

03 Palette

Black creates a single-color monochrome palette. Duotone creates a randomized saturated accent. Add a stop by clicking the ramp; select and drag stops to tune the transition, or use the color and position fields for precise edits. Remove stops with the button or by dragging down. A single stop produces monochrome output.

04 Plotting & export

Export a PNG preview or an SVG with physical page dimensions. Before plotting, optimize SVG paths with vpype or a similar tool.

Plots can become dense quickly. An iDraw 2.0 on A3 takes about an hour for 20,000 dots. Dense areas use more ink; start with a full reservoir or a fresh pen.
